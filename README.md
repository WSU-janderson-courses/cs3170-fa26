# CS 3170 — Mobile App Development

Welcome to the course repository for **CS 3170: Mobile App Development**.

This repository contains code and resources used in class, including Android Studio examples, Kotlin practice code, and completed versions of selected activities and projects.

Our development work focuses on **Kotlin**, **Android Studio**, and **Jetpack Compose**.

## Getting Started

If you're new to Git or Classroom 50, start with these guides:

1. **[Install Git](git_install.md)** — Resources for installing and configuring Git.
2. **[Set up Classroom 50](classroom_50.md)** — Instructions for connecting to Classroom 50 and working with assignment repositories. Some examples may reference CS 3100, but the setup process is the same for this course.

Use the assignment repositories provided through Classroom 50 for your submissions. This course repository is primarily a place for reference materials and examples.

### Kotlin Examples

The [`kotlin/`](kotlin/) directory contains:

- [`kotlin_examples.kt`](kotlin/kotlin_examples.kt) — Examples demonstrating Kotlin language features covered in class.
- [`README.md`](kotlin/README.md) — Links to Kotlin Playground examples added throughout the semester.

The [Kotlin Playground](https://play.kotlinlang.org/) allows you to run and modify Kotlin code directly in your browser without creating an Android Studio project.

### Android Studio Examples

The [`examples/`](examples/) directory contains projects used during classroom demonstrations.

Each project is a separate Android Studio project. To explore an example, open its individual project directory in Android Studio rather than opening the entire course repository as one Android project.

You're encouraged to experiment with the examples, modify the code, and use them to review material covered in class.

### Completed Activities and Project Solutions

The [`inClass/`](inClass/) directory contains completed versions of in-class exercises and activities, generally made available after grading.

Solutions to larger course projects will be organized separately under [`projects/`](projects/) when that directory is added.

These solutions are intended to help you review concepts, compare different approaches, and understand how the applications are implemented. They are not necessarily the only correct implementations.

## Working with This Repository

You can browse files directly through the repository website or clone the repository to your computer:

```bash
git clone <repository-url>
```

Replace `<repository-url>` with the clone URL shown on the repository's page.

Once cloned, you can open individual Android Studio projects or explore the Kotlin source files.

**This repository is updated throughout the semester.** Check back for new examples, Kotlin Playground links, completed activities, and project solutions.
